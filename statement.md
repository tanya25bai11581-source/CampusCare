# Project Statement – CampusCare

## Problem Statement

Students often need to manage basic health-related information such as student details, doctor appointments, and health records. Managing this information manually can be inconvenient and unorganized.

CampusCare provides a simple console-based Java system to organize these basic health management activities in one application.

## Scope

The project focuses on basic student health management through a console interface. It allows users to manage student information, appointments, and health records.

## Target Users

- College students
- College health centres
- Student support staff

## High-Level Features

- Student Management
- Appointment Management
- Health Record Management
- Appointment reminder background task
- Exception handling
- File handling

## Project Objectives

- Provide a simple system for managing student health information.
- Organize appointment and health record information.
- Demonstrate core Java programming concepts.
- Apply object-oriented and modular programming principles.
- Provide a user-friendly console-based workflow.

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- File I/O
- Multithreading
- GitHub
